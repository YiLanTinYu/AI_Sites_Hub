# 惠选AI同类站对比

本文档用于记录同类 AI 导航、AI 比价和模型价格站的能力差异，后续改版优先补齐这里列出的高价值能力。

## 对比结论

惠选AI当前的差异化方向不应只做“AI 产品列表”，而是围绕“惠选”二字建立三层价值：

1. **优惠**：跟踪官方活动、到期提醒、价格变化和长期成本。
2. **会选**：用场景、预算、使用频率和国内外可用性帮用户缩小选择范围。
3. **可信**：保留官方来源、人工核实时间、变化报告和不可自动判断项。

同类站普遍有一个问题：要么工具很多但缺少价格可信度，要么价格很细但偏开发者，不适合普通用户快速选择。惠选AI可以把“普通用户订阅套餐”和“开发者 API 价格”分开做，避免信息混在一起。

## 竞品功能对比

| 站点 | 主要特点 | 比我们强的地方 | 我们应补齐的动作 |
| --- | --- | --- | --- |
| [Futurepedia](https://www.futurepedia.io/) | 大规模 AI 工具导航、分类和内容生态 | 工具数量多，分类覆盖广，适合发现新产品 | 继续增强“新 AI 产品候选发现”，增加每周精选候选和收录理由 |
| [Product Hunt](https://www.producthunt.com/) | 新产品发布和社区热度 | 能及时发现新项目和热度趋势 | 把 Product Hunt、Hacker News、GitHub、Hugging Face 作为候选来源，不直接发布 |
| [AI API Prices](https://aiapiprices.com/) | API 价格横向比较、排序、成本估算 | 开发者价格表清晰，适合按输入输出成本比较 | 模型价格页继续强化排序、筛选和费用计算器 |
| [LLM Cost Hub](https://llmcosthub.com/pricing/) | LLM API 价格、能力筛选、收藏比较 | 过滤维度细，适合开发者短名单比较 | 给模型价格页增加更细的能力筛选，如工具调用、JSON、免费层、上下文 |
| [ComputeUnion](https://www.computeunion.net/) | 大量模型和 GPU 价格追踪 | 覆盖数量大，更新频率高 | 不盲目追求数量，优先主流厂商和中文用户能核实的官方来源 |
| [AI Pricing Guru](https://www.aipricing.guru/) | API 与订阅价格、排行榜和计算工具 | 价格工具化程度高 | 套餐页增加排序、预算筛选、场景筛选和更清晰的适合人群 |

| [Model Cost Comparison](https://modelcostcomparison.com/) | 多模型成本比较 | 成本换算直观 | 费用计算器增加“常见使用量模板”，减少用户自己填 Token 的压力 |
| [AI Model Matrix](https://ai-model-matrix.com/) | 模型矩阵和多维比较 | 横向对照强 | 模型详情页增加能力矩阵和同价位替代方案 |

## 近期优先级

### P0：普通用户选择体验

- 套餐页增加场景筛选、预算筛选、免费筛选和排序。
- 场景推荐页拆分为独立页面，方便搜索引擎收录“日常问答 AI 怎么选”等长尾词。
- 首页 30 秒选 AI 的推荐逻辑避免同一家产品刷屏，每家厂商只保留一个主流选择。

### P1：优惠提醒和日常维护

- GitHub Actions 每日生成优惠监测报告。
- 有变化、异常或临期活动时，用 Webhook 或 Server 酱推送提醒。
- 自动化只提醒，不直接修改线上数据；价格和优惠仍需人工核实官方来源。

### P2：内容与 SEO

- 每个场景页都要回答三个问题：适合谁、怎么选、推荐哪些产品。
- 每个套餐卡片保持官方来源链接，避免用户怀疑价格来源。
- 后续可以增加“免费 AI 推荐”“国内可用 AI 推荐”“写作 AI 推荐”等专题页。

## 不做什么

- 不把未经核实的第三方转述价格直接发布。
- 不为了追求数量收录大量没有官网、无法核实或长期不可用的产品。
- 不把 API Token 价格和普通会员月费混在一个最低价排名里。
- 不让商业推广改变推荐规则；有返佣或赞助必须明确标注。
